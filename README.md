# เว็บไซต์ตัวอย่าง ทรัพย์สิริ แกรนด์ กรุ๊ป

เว็บไซต์รุ่นแรกแบบ responsive สร้างด้วย Next.js, TypeScript และ vinext ประกอบด้วยหน้าแรก หน้ารวมที่ดิน หน้ารายละเอียดที่ดิน หน้าเกี่ยวกับเรา และหน้าติดต่อ

## เริ่มต้นใช้งานในเครื่อง

ต้องมี Node.js 22.13 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด URL ที่แสดงใน Terminal (โดยทั่วไปคือ `http://localhost:3000`)

ตรวจสอบก่อนส่งมอบ:

```bash
npm run lint
npm run build
```

## การแก้ไขข้อมูล

- ข้อมูลที่ดินทั้งหมดอยู่ใน `data/properties.ts`
- คอมโพเนนต์ที่ใช้ร่วมกันอยู่ใน `components/`
- แต่ละหน้าอยู่ใน `app/`
- รายละเอียดที่ดินใช้ route กลาง `app/land/[slug]/page.tsx`

ฟิลด์ `image`, `status`, `mapUrl` และ `youtubeUrl` ถูกเตรียมไว้สำหรับทุกแปลงแล้ว รุ่นแรกใช้ภาพกราฟิกและลิงก์ placeholder ซึ่งต้องแทนที่ด้วยข้อมูลจริงที่ได้รับอนุญาตก่อนเผยแพร่

## ขั้นตอนถัดไปสำหรับ Netlify (ยังไม่ได้เชื่อมต่อ)

1. ตรวจทานข้อความ ราคา สถานะ เอกสารสิทธิ์ รูปภาพ และลิงก์ทั้งหมด
2. เพิ่มรูปภาพที่ได้รับอนุญาตใน `public/` แล้วปรับ field `image` หรือเปลี่ยนคอมโพเนนต์ให้ใช้ `next/image`
3. ทดสอบทุกหน้าบนมือถือและคอมพิวเตอร์
4. เมื่อต้องการเผยแพร่จริง ให้สร้าง repository ตามกระบวนการของบริษัท แล้วเชื่อม repository นั้นกับ Netlify
5. ตั้ง Build command เป็น `npm run build` และตรวจสอบ adapter/runtime ที่ต้องการใช้กับ Next.js เวอร์ชันปัจจุบันใน Netlify ก่อน deploy
6. เพิ่มโดเมน ตัวแปรแวดล้อม และนโยบายความเป็นส่วนตัวตามระบบจริง

> โปรเจกต์รุ่นนี้ไม่ได้เชื่อม Netlify หรือ GitHub และไม่มีการ publish/push โค้ด
